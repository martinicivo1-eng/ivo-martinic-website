# Ivo Martinić — osobna web-stranica

Minimalistička osobna stranica na hrvatskom jeziku s informacijama o obrazovanju, projektima, instrukcijama i kontaktima.

## Objavljivanje putem GitHub Pages

1. Otvorite **Settings → Pages** u ovom repozitoriju.
2. U odjeljku **Build and deployment** odaberite **Deploy from a branch**.
3. Odaberite granu `main` i mapu `/(root)`, zatim kliknite **Save**.
4. Kada objava završi, stranica će biti dostupna na:

   https://martinicivo1-eng.github.io/ivo-martinic-website/

Izmjene u `index.html` na grani `main` ažurirat će web-stranicu nakon objave.

## Tehnologije

- HTML
- CSS
- JavaScript

Nije potreban build korak ni vanjski paket.
